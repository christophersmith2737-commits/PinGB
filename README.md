# 拼好豆 PinGB

上传任意图片，一键生成拼豆底稿。

**网页端**: https://pingb.350234235.xyz/

## 功能

- **图片转像素画**：上传 JPG/PNG，可调粒度和相似度阈值，多种池化策略
- **逆向图纸识别**：导入不带色号的拼豆像素图/图纸照片，手动标定 X/Y 轴建立网格，自动逐格采样并映射色号（详见下文）
- **多店家色号**：支持 MARD / COCO / 漫漫 / 盼盼 / 咪小窝，全局一键切换
- **智能噪点识别**：自动标记数量 ≤3 的疑似杂色，预览图金色高亮定位
- **差值补色**：5×5 邻域最高频颜色自动替换噪点，支持逐个或批量
- **去除杂色**：点击排除任意颜色，智能重映射到最近似可用色
- **手动编辑**：画笔、调色盘、放大镜、改色模式、消散效果、一键加边框
- **AI 优化**：接入即梦 4.0 智能优化图片，支持一键去背景
- **沉浸式拼豆**：任务队列引导，边框→填充渐进，实时计时和进度
- **下载导出**：带色号 PNG 图纸（粗线+细线网格）、颜色统计图（按数量降序）、CSV 数据

## 逆向图纸识别

将一张"不带色号的拼豆图纸"直接变成可编辑的 PinGB 工程数据。

1. 上传图纸图片，点击 **"是像素图"** 按钮进入识别模式
2. **标定 X 轴**：点击放置起点和终点（自动吸附水平/垂直）。每个点放置后可用 **WSAD 微调**（每次 1 像素，Shift 加速 10 像素）——起点四方向自由移，终点锁定在轴上只能左右移；**Enter** 确定当前点，输入该线段包含的格子数
3. **标定 Y 轴**：点击放置终点（自动强制垂直于 X 轴），放置后可用 W/S 沿轴微调（左右锁定），Enter 确定，输入格子数
4. **调整网格**：向上/下/左/右扩展行列，直到网格覆盖整个图案
5. **采样**：选择中心点采样（默认）、五点投票采样或九点投票采样。投票采样中每个点**先各自映射色号再计票**，结果必为某采样点映射出的色号（不做 RGB 平均）：五点 = 中心 3 票 + 上下左右各 2 票；九点 = 中心 5 票 + 8 方向各 2 票；抗网格线/压缩噪声
6. **审视结果**：原图/识别结果切换，点击格子改色（色板快选或自定义取色）
7. 确认导入后即可进入现有编辑器、色号统计、图纸导出和沉浸式拼豆模式

标定过程中光标旁有实时放大镜辅助精确定位。

> 核心原则：用户负责告诉软件网格在哪里，软件负责完成矩阵建立、颜色采样和色号映射。

## 技术栈

Next.js 15 + React 19 + TypeScript + Tailwind CSS 4 + Cloudflare Pages

## 开发

```bash
npm install
npm run dev        # 本地开发 http://localhost:3000
npm run build      # 生产构建
npm run lint       # ESLint
```

## 部署

```bash
npm run build
npm run pages:deploy
```

需要 AI 功能时配置环境变量（参考 `.env.example`）：
- `VOLC_ACCESS_KEY_ID` — 火山引擎 Access Key
- `VOLC_SECRET_ACCESS_KEY` — 火山引擎 Secret Key
- `REMOVEBG_API_KEY` — remove.bg API Key（可选）
