# 拼好豆 PinGB — 软件功能综述

## 一、产品定位

PinGB（拼好豆）是一款面向拼豆（Perler Beads / Hama Beads）爱好者的 **AI 辅助图纸生成工具**。用户上传任意照片或图片，软件自动将其转换为可在现实中用拼豆制作的标准化图纸。支持 Web 端使用，可安装为 PWA 桌面/移动端应用。

**技术栈**：Next.js 15 (React 19) + TypeScript + Tailwind CSS 4 + Cloudflare Pages（静态导出 + Functions）

**在线地址**：https://pingb.350234235.xyz/

## 二、核心工作流

### 2.1 图片导入
- 支持 **JPG / PNG** 格式拖拽上传或点击选择
- 支持 **CSV 数据导入**（可恢复之前导出的编辑状态）
- 导入后自动弹出裁剪窗口

### 2.2 图片裁剪
- 集成 Cropper.js，支持自由裁剪、旋转（±90°）、水平/垂直翻转、重置
- 裁剪窗口右下角提供**颜色数量限制**选项（勾选后输入 3–221，采样色号自动控制在 N 种以内，超出部分按 CIELAB ΔE 色差合并到最近似高频色）

### 2.3 AI 优化（可选）
- **AI 色彩增强**：接入即梦 4.0 API（火山引擎），智能优化图片色彩饱和度和对比度
- **智能抠图**：双引擎支持 —
  - 用户填入 remove.bg API Key → 调 remove.bg 云端抠图
  - 未填 Key → 兜底使用火山引擎 entity_seg 实体分割
- 两种优化均保留原始分辨率，不受后续像素化参数影响

### 2.4 像素化参数调节
- **横向格子数 N**：10–300，控制像素画粒度
- **色差阈值**：0–100，低于阈值的相似颜色自动合并为同一色号

### 2.5 像素化算法
- 将图像划分为 N×M 网格，每个格子取**平均 RGB**
- 通过 **CIELAB ΔE76 色差公式**（比 RGB 欧氏距离更贴合人眼感知）映射到标准拼豆色板
- 按频率降序进行全局相似色合并

## 三、多店家色号系统

软件内置 **291 个标准 hex 颜色**，映射到 **5 个主流店家色号体系**：

| 色号系统 | 说明 |
|---------|------|
| MARD    | 默认系统 |
| COCO    | Coco 家色号 |
| 漫漫    | 漫漫拼豆店色号 |
| 盼盼    | 盼盼拼豆店色号 |
| 咪小窝  | 咪小窝拼豆店色号 |

- 全局一键切换色号系统，**所有 UI 同步更新显示**（画布标注、颜色列表、下载图纸、统计数据）
- 数据源：`src/app/colorSystemMapping.json`（291 条 hex → 五系统映射）

## 四、手动编辑系统

### 4.1 编辑模式
| 模式 | 功能 |
|------|------|
| **手动上色** | 从浮动调色盘选色，点按像素格子上色 |
| **画笔模式** | 可调半径 1–50 的笔刷，支持 Shift 追加连续绘制，Ctrl+滚轮调节大小 |
| **橡皮擦** | 点击/笔刷擦除像素（设为透明） |
| **改色模式** | 点击单个像素弹出悬浮窗口，可选邻色、手动输入色号，支持"替换所有同色"或"只替换当前像素"，支持 Ctrl+Z 撤销 |
| **颜色替换** | 选择源颜色 → 选择目标颜色 → 全图替换 |
| **消散效果** | 划定选区 → 设置角度/强度/种子 → 像素沿方向飘散（粒子效果） |

### 4.2 浮动工具栏
- **取色/橡皮/改色/画笔切换**，Esc 退出
- 笔刷半径实时调节
- **撤销按钮**（最多保留 30 步历史），Esc 退出笔刷模式

### 4.3 放大镜工具
- 像素级精确编辑，高倍放大选区
- 可在放大视图下直接点按格子改色

### 4.4 一键加外边框
- 自动检测图纸外部轮廓，为最外层非透明像素统一添加边框颜色（默认 H07 色号）
- 使用 BFS 洪水填充算法，内部镂空区域不受影响

## 五、颜色管理

### 5.1 自定义色板
- 从 291 色中自由勾选启用的颜色
- 色板编辑器支持预设方案、全选/全不选
- 选择持久化到 localStorage

### 5.2 去除杂色
- 点击颜色列表任意色块可**排除该颜色**，自动将使用该色的格子重映射到最近似可用色
- 排除色列表可展开查看，支持一键恢复或**手动替换为指定色号**
- 智能限制：如果排除会导致无可用颜色，则阻止操作

### 5.3 智能噪点识别与补色
- 一键扫描数量 ≤3 的疑似噪点颜色
- 画布上高亮所有噪点像素（金色脉冲动画）
- **差值补色**：对每个噪点取 5×5 邻域（24 格），用占比最高的颜色自动替换
- 支持单色补色和批量一键补色

### 5.4 色相排序
- 颜色列表不按色号字母排序，按**色相（HSL）排列**，同色相聚，视觉更直观

## 六、下载导出

### 6.1 带色号图纸 PNG
- 每个格子标注对应店家色号
- 可配置参数：
  - **网格线**：粗实线（可调间隔）+ 细虚线
  - **网格线颜色**：深灰/红/蓝/绿/紫/橙可选
  - **坐标标注**：行列编号
  - **色号显示**：每格标注
- 高亮噪点模式下载（噪点格子用特殊颜色标记）

### 6.2 颜色统计图
- 色块 + 色号 + 数量，按占据格数降序排列
- 可附带在图纸下方一并下载

### 6.3 CSV 导入导出
- 导出：hex 颜色数据的 CSV，可用于 Excel 统计或重新导入
- 导入：恢复之前的编辑状态（包括像素数据、网格尺寸、颜色统计）

## 七、辅助高效拼豆模式（`/focus`）

专为**实际拼豆操作**设计的导引界面：

### 7.1 任务队列生成
- 自动分析图纸，生成智能拼豆顺序：
  - **边框优先**：先完成轮廓，建立边界感
  - **同色内部填充**：同色相邻格子归为一个任务，减少换色频率
- 每个任务 ≤15 个豆子，避免单步太大

### 7.2 交互体验
- START 按钮 + 3 秒倒计时启动
- **实时进度追踪**：已完成 / 当前任务 / 未完成三种视觉状态
- **计时器**：记录拼豆耗时
- 完成后显示总用时

### 7.3 画布操作
- 缩放 + 拖拽，支持双指捏合（移动端）
- 当前任务高亮，已完成区域标记

### 7.4 数据安全
- 进入前弹出备份提醒，建议先下载 CSV 存档

## 十、技术亮点

1. **CIELAB ΔE76 色差算法**：比传统 RGB 欧氏距离更贴合人眼颜色感知，在浅色和深色区域都更准确
2. **双引擎抠图**：客户端传 Key 走 remove.bg，否则自动兜底火山引擎 entity_seg
3. **颜色数量硬限制**：用户可设定最终使用的色号数量上限，超出部分自动按色差合并
4. **Portal 悬浮弹窗**：改色弹窗通过 React Portal 渲染到 document.body，不会被容器 overflow 裁剪
5. **静态导出架构**：Next.js `output: export` + Cloudflare Functions，兼顾静态页面性能和动态 API 需求
6. **完整的撤销系统**：30 步深拷贝撤销栈，支持换色模式 Ctrl+Z
